# Kiran Hombal's Personal Website

Personal academic website for [Kiran Hombal](https://kstark007.github.io/).

## Discovery files

`sitemap.xml`, `blog/feed.xml` and the post list inside `llms.txt` are all
generated by `.github/scripts/stamp_dates.py` at deploy time, from the JSON-LD
each post already carries. Adding a post therefore means editing `blog/index.html`
only — the other three follow, and the script fails the build if a post it finds
on disk is missing from the index's `blogPost` list.

The script also stamps each page's `dateModified` from `git log`, so the dates
cannot drift the way a hand-maintained literal does. The copies committed here
are what the last run produced; the deployed copies are regenerated.

To test it without deploying, run it against a scratch copy — it rewrites files
in place:

```sh
rsync -a --exclude=.git ./ /tmp/site-test/ && cp -R .git /tmp/site-test/.git
cd /tmp/site-test && python3 .github/scripts/stamp_dates.py
```

`robots.txt` allows every crawler, AI crawlers included, and disallows only the
framework build artifacts inside an exported post (`_next/`, the `__next.*.txt`
React Server Component payloads, and the export's 404 routes), which would
otherwise be a second, unreadable copy of the post.

## Blog posts

A post is either a single HTML file in `blog/`, or a self-contained static export
in `blog/<slug>/`. The one export here is built from a separate repository and
copied in wholesale:

```sh
cd ../agentic_workload_analysis_website
NEXT_PUBLIC_BASE_PATH=/blog/agentic-coding-in-the-wild npm run build
rsync -a --delete out/ ../KSTARK007.github.io/blog/agentic-coding-in-the-wild/
```

That build emits `index.md`, `llms.txt` and `figure-data.json` alongside the HTML:
a machine-readable rendition carrying the full prose plus every figure as a data
table. The post's `<head>` advertises it with `<link rel="alternate" type="text/markdown">`.

## Fonts

The site uses [Computer Modern Unicode](https://cm-unicode.sourceforge.io/) Sans Serif
(`cmunss` regular, `cmunsx` bold), shipped as WOFF2 subset to Latin-1 + General
Punctuation. To regenerate from the upstream TTFs:

```sh
pip install fonttools brotli
pyftsubset cmunss.ttf \
  --unicodes="U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+2000-206F,U+2074,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD" \
  --layout-features='*' --flavor=woff2 --output-file=assets/fonts/cmunss.woff2
```
